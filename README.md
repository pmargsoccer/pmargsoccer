# Fala, Brasil! 🇧🇷

An 8-week Brazilian Portuguese course built around a trip to Brazil: **grammar → sentences → speaking → fluency**.

Open `index.html` in a browser, or host it free with GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).
Use **Chrome or Edge** for pronunciation scoring (Web Speech API). Everything else works in any browser.

## How it works
- **56 sessions, one per day.** Each week has 4 lessons, a speaking lab, a mixed drill and a checkpoint test (80% = pass).
- **Daily routine (60–90 min):** flashcards (spaced repetition) → main session → 20 speaking reps → immersion → couples challenge.
- **Tracking:** real study minutes (counted automatically while you're active), streak, schedule status (ahead/behind),
  a heatmap of your days, words learned, speaking reps, checkpoint scores, can-do self-ratings, an estimated CEFR level and weak spots.
- **Two people:** each partner gets a profile, and a couple scoreboard compares you. Progress is stored in the browser (localStorage).
  Use Settings → Export/Import to move it between devices.

## Curriculum
| Week | Focus |
|---|---|
| 1 | Pronunciation, greetings, ser, gender & numbers |
| 2 | Present tense, questions, ser vs estar, ter/ir |
| 3 | Irregular verbs, future (vou + verb), prepositions |
| 4 | Past tense, restaurants, directions, hotels |
| 5 | Imperfect, preterite vs imperfect, pronouns, comparisons |
| 6 | Real spoken Portuguese, commands, subjunctive, opinions |
| 7 | Future subjunctive, hypotheticals, storytelling, slang |
| 8 | Trip simulations (arrival, social, emergencies, romance) + final exam |

Content lives in `data/week*.js` and is easy to extend.
